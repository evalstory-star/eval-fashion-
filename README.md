# EVAL | متجر إيفال للأزياء الراقية والعبايات

متجر إلكتروني عصري وآمن لعلامة **EVAL Fashion** في مصر، يجمع بين الفخامة، الاحتشام، والتقنيات الحديثة مع لوحة تحكم كاملة الصلاحيات للإدارة.

## ✨ صلاحيات لوحة تحكم المدير (Super Admin):
- **إضافة وحذف الأقسام:** التحكم الكامل بتصنيفات المتجر (عبايات، فساتين، طرح، كاجوال، وغيرها) مع ظهورها الفوري في شريط التصفح وقوائم المنتجات.
- **تخصيص غلاف المتجر:** تغيير صورة الغلاف مع توفير نماذج أغلفة ملكية سريعة.
- **تعديل نصوص الغلاف:** تعديل الشارة، العنوان الرئيسي، والنص التسويقي للغلاف.
- **تخصيص اللوغو:** تعديل اسم المتجر النصي، الشعار الفرعي (Slogan)، ورابط صورة اللوغو.
- **تعديل الأسعار وإضافة خصومات:** تعديل أسعار أي قطعة في المتجر وإضافة السعر الأصلي لاحتساب وعرض نسبة الخصم تلقائياً ().
- **تعديل رأس الصفحة:** تعديل نص شريط الإعلانات العلوي والتحكم بإظهاره أو إخفائه.
- **لوحة بيانات المبيعات:** رسوم بيانية تفاعلية باستخدام Recharts وخاصية التكبير والتصغير (Zoom & Brush) والتكبير بملء الشاشة.
- **سلة مشتريات واتساب:** إرسال تفاصيل الطلب والمقاسات والألوان مباشرة إلى رقم الواتساب المعتمد (+201108396536).
- **قائمة الأمنيات (Wishlist):** حفظ القطع المفضلة بنقرة واحدة ونقلها للسلة دفعة واحدة.
- **مستشار الأزياء الذكي:** مدعوم بالذكاء الاصطناعي (Gemini).
