# EVAL | متجر إيفال للأزياء الراقية والعبايات

متجر إلكتروني عصري وآمن لعلامة **EVAL Fashion** في مصر، يجمع بين الفخامة، الاحتشام، والتقنيات الحديثة.

## ✨ المميزات الرئيسية
- **كتالوج أزياء فاخر:** عبايات كريب ملكي، فساتين حريرية، أطقم كاجوال، وطرح شيفون بجودة فائقة وأسعار بالجنيه المصري (ج.م).
- **قائمة الأمنيات (Wishlist):** حفظ القطع المفضلة بنقرة واحدة ونقلها للسلة دفعة واحدة.
- **سلة مشتريات واتساب:** إرسال تفاصيل الطلب والمقاسات والألوان مباشرة إلى رقم الواتساب المعتمد (+201108396536).
- **لوحة بيانات المبيعات (Sales Analytics):** رسوم بيانية تفاعلية باستخدام Recharts مع خاصية التكبير الزمني (Zoom & Brush) والتكبير بملء الشاشة.
- **مستشار الأزياء الذكي (Gemini AI Stylist):** استشارات أزياء مخصصة وتنسيق الأقمشة بالذكاء الاصطناعي.
- **تحصين أمني شامل:** تشفير كلمات المرور باستخدام SHA-256، حماية ضد ثغرات XSS، وسكريبت حماية Supabase RLS.

## 🚀 النشر
- المتجر مجهز للنشر المباشر على **Netlify** و **GitHub Pages**.
- تم بناؤه باستخدام React 19 + TypeScript + Vite + Tailwind CSS.
