# EVAL Fashion | متجر إيفال للأزياء والعبايات

متجر إلكتروني فاخر للأزياء والعبايات في مصر مع تجربة تسوق سريعة، سلة واتساب مباشرة، ومستشار ذكاء اصطناعي، ولوحة تحكم محمية ومشفرة بإدارة كاملة لصلاحيات الموظفين.

## 🔐 الأمان ولوحة التحكم المخفية
- **الدخول المخفي**: لا توجد أزرار إدارية ظاهرة للعملاء حفاظاً على هوية المتجر الفاخرة.
- **طرق الوصول للمدير**:
  1. إضافة  أو  لنهاية الرابط.
  2. النقر 4 مرات سريعة على شعار المتجر (EVAL) في أعلى الصفحة أو حقوق المتجر في الأسفل.
  3. اختصار لوحة المفاتيح:  (أو ).
- **نظام الموظفين والصلاحيات (RBAC)**:
  - المدير العام يتحكم بإنشاء حسابات الموظفين، تحديد صلاحيات كل موظف (مبيعات، منتجات، أقسام، إعدادات المتجر)، تعطيل الحسابات، أو حذفها نهائياً.
  - تشفير كلمات المرور باستخدام SHA-256 وحماية من هجمات التخمين بعد 5 محاولات خاطئة.
